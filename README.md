Zomato Order & Restaurant Analysis

Project Overview

This project analyzes Zomato restaurant and order data using Power BI, MySQL, and Excel. It focuses on restaurant performance, sales, order patterns, delivery time, customer ratings, and location-based revenue.
The project transforms raw data into interactive visualizations to help understand business performance and support data-driven decision-making.

Objectives

- Analyze the number of restaurants across cities.
- Identify top-performing restaurants by total sales.
- Compare order distribution across cities.
- Track order amounts over time.
- Analyze revenue by city and area.
- Monitor delivery time and customer ratings.
- Build an interactive dashboard with key performance indicators (KPIs).

 Dataset

The project brief describes two datasets:

1. Zomato Orders
- Order ID
- Restaurant ID
- Customer ID
- Order date and time
- Delivery time
- Total order cost
- Item count
- Payment method
- Customer rating

2. Zomato Restaurants
- Restaurant ID and name
- City and area
- Cuisine
- Average rating
- Total ratings
- Price range
- Delivery availability

Tools & Technologies

- Power BI – Interactive dashboards and data visualization
- MySQL – Data import, SQL queries, joins, and aggregation
- Microsoft Excel – Data preparation and transformation
- DAX – Calculated measures and KPI analysis
- Power Query – Data cleaning and transformation

Power BI Report

Page 1: Executive Overview

This page provides a summary of restaurant and order performance through charts and KPI cards.

Visualizations:
- Number of restaurants in each city
- Total orders by city
- Top 5 restaurants by total order cost
- Order amount trends over time

Key Performance Indicators:
- Total Revenue
- Orders per Restaurant
- Total Orders
- Total Restaurants
- Average Order Value
- Average Delivery Time
- Average Customer Rating

Interactive filters:
- City
- Price Range
- Month and Year

Page 2: Revenue & Order Density

This page focuses on geographical distribution and location-based performance.

Visualizations:
- Revenue by city using a treemap
- Order distribution by city and area using a map
- Total orders across cities and areas in a table

Interactive filters:
- City
- Area

These visuals help users explore revenue distribution and identify locations with higher or lower order volumes.

Key Analysis Areas

- Restaurant distribution by city
- Restaurant-wise sales performance
- Revenue and order trends
- Average order value
- Delivery time and customer ratings
- City-wise and area-wise order density
- Location-based revenue comparison

Business Recommendations

- Monitor top-performing restaurants to understand their sales performance.
- Use city-wise order patterns to identify potential growth opportunities.
- Review delivery times and customer ratings to identify areas for service improvement.
- Analyze revenue by area to support location-based business decisions.
- Use interactive filters to compare performance across cities, areas, price ranges, and periods.

Conclusion

This project demonstrates how Power BI can turn restaurant and order data into meaningful business insights. The interactive report brings key performance indicators, sales trends, restaurant performance, and location-based analysis together to support better business decisions.
